# Introduction to Data Engineering

A hands-on course that builds one small but complete data platform, from raw files to an AI application on curated data, on your own laptop.

> **Status: under construction.** The course is being written one module at a time, from specs. Nothing here is ready to study yet.

## How this repository is built

Every module starts as a spec that is reviewed before any content is written.

- [`specs/constitution.md`](specs/constitution.md): the rules every module follows
- [`specs/course.md`](specs/course.md): audience, learning outcomes, syllabus and stack
- [`specs/modules/`](specs/modules/): one folder per module, with its spec, plan and tasks
