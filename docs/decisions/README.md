# Decision records

One short file per design decision: the options that were considered, the choice, and the reason. They explain why the course looks the way it does, and they are part of what the course teaches.

Files are numbered in the order the decisions were made: `0001-object-storage.md`, `0002-hardware-requirement.md`, and so on.

## Template

```
# NNNN. Title

Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD

## Context

What needed deciding, and what constrained the choice.

## Options

What was considered, with the evidence for each.

## Decision

What was chosen.

## Consequences

What this makes easier, what it makes harder, and what would make us revisit it.
```
