# Data dictionary

Every table the course builds, with each column, its meaning and its source. A module is not done until the tables it produces are described here.

No tables exist yet. The first entries arrive with the bronze layer in module 2.

## Format

Each table gets a section like this:

```
## layer.table_name

One sentence on what a row represents.

- Built in: module N
- Source: where the data comes from
- Quality checks: which checks cover this table

| Column | Type | Meaning | Source |
| --- | --- | --- | --- |
```
